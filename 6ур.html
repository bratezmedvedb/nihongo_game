Грамматика 6 Уровня: Конструкции со словарной формой

3 основные грамматические конструкции:

1. [Слов. форма] + ことができます — Потенциал / возможность (Могу / Можно сделать)

2. [Слов. форма] + まえに (前に) — Предшествование (Перед тем как сделать...)

3. [Слов. форма] + と — Естественное условие (Если / когда делаешь, то неизбежно...)


Образование:

Все эти конструкции присоединяются напрямую к словарной (начальной) форме глагола без каких-либо изменений корня:

• 会う → 会うことができます / 会うまえに / 会うと
• 食べる → 食べることができます / 食べるまえに / 食べると
• する → することができます / するまえに / すると
• 来る → 来ることができます / 来るまえに / 来ると
